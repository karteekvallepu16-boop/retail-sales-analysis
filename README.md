📊 Retail Sales Data Analysis Project
Project Overview
This project focuses on analyzing retail sales data to understand sales performance, customer purchasing patterns, and business trends using PostgreSQL and Tableau.
🎯 Project Objectives
Analyze overall retail sales performance.
Identify purchasing trends.
Understand product and category performance.
Analyze customer purchasing behaviour.
Create an interactive Tableau dashboard.
🛠️ Tools & Technologies
PostgreSQL: Data analysis and SQL queries.
Tableau: Interactive dashboard and data visualization.
CSV: Dataset storage and data handling.

Sales performance analysis.
